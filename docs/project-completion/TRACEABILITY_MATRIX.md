# Requirement traceability matrix

Maps each requirement area of the product brief to where it is implemented, how it is tested and where it is documented. "Status" uses the words of `IMPLEMENTATION_STATUS.md`: **Verified** means automated tests ran and passed in the build sandbox and CI; it does not mean deployed or used by real people. Screen-level traceability to the 22 reference images is in `SCREEN_TRACEABILITY.md`.
