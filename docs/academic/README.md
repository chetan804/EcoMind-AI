# Academic deliverables

Documents for the project report and the viva. They were brought up to date on 2026-10-22 and describe **this repository as it is** (Alembic head 0017, `main` at `625241e` plus the documentation branch): every number is
taken from a committed report or a test run named next to it, and every external reference was looked up
and is listed with where it was found. Where something was not measured, the text says so.

| File | Content |
|---|---|
| [abstract.md](abstract.md) | Abstract and keywords |
| [objectives.md](objectives.md) | Problem statement, objectives, scope, and the status of each objective |
| [literature-survey.md](literature-survey.md) | Verified sources only, and what each contributes to the design |
| [methodology.md](methodology.md) | Architecture, data, models, forecasting, routing, evaluation protocol |
| [results.md](results.md) | Measured results and their limits |
| [user-manual.md](user-manual.md) | How each role uses the system |
| [viva-outline.md](viva-outline.md) | Talking points and likely questions with honest answers |
| [ethics-and-data-statement.md](ethics-and-data-statement.md) | Draft ethics, dataset-licence, privacy and AI statements, with the owner-only decisions marked |
| [PAPER_READINESS.md](PAPER_READINESS.md) | Verdict on publishing a research paper, the gaps, a suggested paper structure and a pre-submission checklist |
